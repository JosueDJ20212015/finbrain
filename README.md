# finBrain

> 🏆 **Ganador del Primer Lugar** en la **primera edición de la Feria de Proyectos de Ciencia y Tecnología (FCC 2026)** de la **Universidad Tecnológica de Honduras (UTH)**.

Proyecto Flutter con Firebase Auth + Google Sign-In.

## 🏆 Reconocimiento

Este proyecto fue reconocido con el **Primer Lugar** durante la primera edición de la **Feria de Proyectos de Ciencia y Tecnología (FCC 2026)** organizada por la **Universidad Tecnológica de Honduras (UTH)**, destacándose por su innovación, desarrollo técnico y aporte tecnológico.

## 📰 Aparición en medios

El proyecto fue destacado por un periódico de circulación nacional:

- **El Diario HN:** https://www.eldiario.hn/uth-celebra-el-ingenio-tecnologico-en-la-feria-de-proyectos-fcc-2026/

## Requisitos

- Flutter instalado
- Android Studio instalado
- Cuenta de Firebase configurada

## Pasos para ejecutar

```bash
git clone https://github.com/JosueDJ20212015/finbrain.git
cd finbrain
```

```bash
flutter pub get
flutter run
```
